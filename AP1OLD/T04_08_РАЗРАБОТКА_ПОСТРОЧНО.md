## G.1.2 — `AuthFilter.isPublicPath`

```java
String path = httpRequest.getRequestURI();
if (isPublicPath(path)) {
    chain.doFilter(request, response);
    return;
}
```

| Строка | Смысл |
|--------|-------|
| `getRequestURI()` | путь без query: `/js/auth.js` |
| `chain.doFilter` | пропустить дальше **без** проверки пароля |
| `return` | **не** выполнять код ниже (иначе 401 на CSS) |

```java
private static boolean isPublicPath(String path) {
    if ("/auth/register".equals(path) || "/auth/login".equals(path)) return true;
    if ("/".equals(path) || "/index.html".equals(path) || "/game.html".equals(path)) return true;
    return path.startsWith("/css/") || path.startsWith("/js/") || path.endsWith(".txt");
}
```

## G.2 — `auth.js` построчно

```javascript
const AUTH_LOGIN_KEY = 'ttt_login';
const AUTH_PASS_KEY = 'ttt_password';
```

Ключи в `sessionStorage` — чтобы не перепутать с другими сайтами.

```javascript
function saveCredentials(login, password) {
    sessionStorage.setItem(AUTH_LOGIN_KEY, login);
    sessionStorage.setItem(AUTH_PASS_KEY, password);
}
```

| Строка | Смысл |
|--------|-------|
| `setItem` | запись в память **вкладки** |
| два ключа | логин и пароль отдельно |

```javascript
function authHeader() {
    const creds = getCredentials();
    if (!creds) return {};
    const token = btoa(creds.login + ':' + creds.password);
    return { 'Authorization': 'Basic ' + token };
}
```

| Строка | Смысл |
|--------|-------|
| `if (!creds) return {}` | нет логина → пустой объект заголовков |
| `btoa(...)` | Base64: `alice:secret` → `YWxpY2U6c2VjcmV0` |
| `'Authorization'` | **с h** — опечатка `Autorization` = вечный 401 |

```javascript
async function apiFetch(url, options = {}) {
    const headers = {
        'Content-Type': 'application/json',
        ...authHeader(),
        ...(options.headers || {})
    };
    const response = await fetch(url, { ...options, headers });
    let body = null;
    const text = await response.text();
    if (text) {
        try { body = JSON.parse(text); } catch { body = text; }
    }
    return { response, body };
}
```

| Строка | Смысл |
|--------|-------|
| `...authHeader()` | spread — вставить `Authorization` |
| `response.text()` | тело как строка (UUID login без кавычек в JSON) |
| `JSON.parse` | если JSON — объект; иначе строка |

```javascript
function logout() {
    if (typeof stopWaitPoll === 'function') stopWaitPoll();
    clearCredentials();
    sessionStorage.removeItem('ttt_userId');
    window.location.href = '/index.html';
}
```

| Строка | Смысл |
|--------|-------|
| `stopWaitPoll` | остановить опрос PvP (функция из game-pvp.js) |
| `removeItem('ttt_userId')` | забыть UUID |
| `location.href` | полная перезагрузка на форму входа |
