## Как устроен браузерный клиент (теория)

```
Браузер                         Spring Boot
────────                        ───────────
index.html  ──register/login──►  POST /auth/register
   │                             POST /auth/login
   │  (сохраняем login:pass
   │   в sessionStorage)
   ▼
game.html   ──fetch + Basic───►  POST /game          (создать)
   │                             POST /game/{id}     (ход)
   │                             GET  /game/{id}     (состояние)
   └── JS рисует доску          AuthFilter проверяет заголовок
```

**Важно:** T04 использует **Basic Auth на каждый запрос**, не «сессионную cookie».  
Браузер **не** отправит пароль сам — JS должен добавить заголовок:

```
Authorization: Basic base64(login:password)
```

Пароль в `sessionStorage` — только для учебного проекта. В проде так не делают.

## Шаг 6.1 — Открыть статику в `SecurityConfig`

**Путь:** `src/main/java/tictactoe/di/SecurityConfig.java`

### Теория

Spring Security по умолчанию блокирует **всё**, кроме того, что ты явно разрешил.  
Сейчас открыты только `/auth/register` и `/auth/login`.  
HTML, CSS, JS — тоже HTTP-запросы → без `permitAll` браузер получит **401** ещё до загрузки страницы.

Статические файлы Spring Boot ищет в:

```
src/main/resources/static/
```

Файл `static/index.html` будет доступен как `http://localhost:8080/index.html`.  
Spring Boot **также** отдаёт `index.html` на `http://localhost:8080/` автоматически.

### Что изменить

В блоке `.authorizeHttpRequests` добавь **перед** `.anyRequest()`:

```kotlin
.requestMatchers(
    "/",
    "/index.html",
    "/game.html",
    "/css/**",
    "/js/**"
).permitAll()
```

Полный фрагмент `securityFilterChain`:

```java
.authorizeHttpRequests(auth -> auth
    .requestMatchers("/auth/register", "/auth/login").permitAll()
    .requestMatchers(
        "/",
        "/index.html",
        "/game.html",
        "/css/**",
        "/js/**"
    ).permitAll()
    .anyRequest().permitAll()
)
```

### ⚠️ Обязательно: тот же bypass в `AuthFilter`

`permitAll` в `SecurityConfig` **не отключает** `AuthFilter`. Без правки фильтра статика всё равно получит **401** (как было с `/auth/register`).

**Путь:** `src/main/java/tictactoe/web/filter/AuthFilter.java`

В `doFilter` **перед** проверкой `Authorization` добавь:

```java
String path = httpRequest.getRequestURI();
if (isPublicPath(path)) {
    chain.doFilter(request, response);
    return;
}
```

И метод:

```java
private static boolean isPublicPath(String path) {
    if ("/auth/register".equals(path) || "/auth/login".equals(path)) {
        return true;
    }
    if ("/".equals(path) || "/index.html".equals(path) || "/game.html".equals(path)) {
        return true;
    }
    return path.startsWith("/css/") || path.startsWith("/js/")
            || path.endsWith(".txt");
}
```

### Пояснение

- `permitAll` в Security — только для Spring Security
- **Реальная** проверка «можно без пароля» — в `isPublicPath` внутри `AuthFilter`
- `/game/**` API **не** в списке — ходы по-прежнему только с Basic Auth

## Шаг 6.2 — `auth.js` (общий модуль авторизации)

**Путь:** `src/main/resources/static/js/auth.js`  
**Создай папки:** `src/main/resources/static/js/`

### Теория

Вынеси auth в **один** файл — иначе скопируешь `btoa(login + ':' + password)` в трёх местах и где-нибудь ошибёшься.

`sessionStorage` — хранилище вкладки браузера:
- пропадает при закрытии вкладки (лучше чем localStorage для пароля)
- доступен только с того же сайта (`localhost:8080`)

### Создай файл целиком

```javascript
const AUTH_LOGIN_KEY = 'ttt_login';
const AUTH_PASS_KEY = 'ttt_password';

function saveCredentials(login, password) {
    sessionStorage.setItem(AUTH_LOGIN_KEY, login);
    sessionStorage.setItem(AUTH_PASS_KEY, password);
}

function clearCredentials() {
    sessionStorage.removeItem(AUTH_LOGIN_KEY);
    sessionStorage.removeItem(AUTH_PASS_KEY);
}

function getCredentials() {
    const login = sessionStorage.getItem(AUTH_LOGIN_KEY);
    const password = sessionStorage.getItem(AUTH_PASS_KEY);
    if (!login || !password) return null;
    return { login, password };
}

function isLoggedIn() {
    return getCredentials() !== null;
}

/** Заголовок Authorization: Basic ... для fetch */
function authHeader() {
    const creds = getCredentials();
    if (!creds) return {};
    const token = btoa(creds.login + ':' + creds.password);
    return { 'Authorization': 'Basic ' + token };
}

/** fetch с JSON + Basic Auth */
async function apiFetch(url, options = {}) {
    const headers = {
        'Content-Type': 'application/json',
        ...authHeader(),
        ...(options.headers || {})
    };
    const response = await fetch(url, { ...options, headers });
    let body = null;
    const text = await response.text();
    if (text) {
        try { body = JSON.parse(text); } catch { body = text; }
    }
    return { response, body };
}

function requireAuth() {
    if (!isLoggedIn()) {
        window.location.href = '/index.html';
    }
}

function logout() {
    if (typeof stopWaitPoll === 'function') stopWaitPoll();
    clearCredentials();
    sessionStorage.removeItem('ttt_userId');
    window.location.href = '/index.html';
}
```

### Пояснение построчно

| Функция | Зачем |
|---------|-------|
| `saveCredentials` | После успешного login сохраняем пару |
| `authHeader` | `btoa` кодирует `login:password` в Base64 |
| `apiFetch` | Обёртка: всегда JSON + Authorization |
| `requireAuth` | На `game.html` — редирект на login если не вошли |
| `logout` | Кнопка «Выйти» — очистка session и переход на `index.html` |

### Проверка шага 6.2

Пока только файл — открой `http://localhost:8080/js/auth.js`.  
Должен отображаться **код JavaScript**, не 401.

## Шаг 6.3 — `index.html` (вход и регистрация)

**Путь:** `src/main/resources/static/index.html`

### Теория

Это **не** Thymeleaf и не JSP — обычный HTML. Spring отдаёт его как статический файл.

Две формы:
1. **Регистрация** → `POST /auth/register` с JSON `{login, password}`
2. **Вход** → `POST /auth/login` с заголовком Basic (проверяем пароль)

После успешного входа → `saveCredentials` → переход на `game.html`.

### Создай файл

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Вход — Крестики-нолики</title>
    <link rel="stylesheet" href="/css/app.css">
</head>
<body>
<div class="wrap">
    <h1>Крестики-нолики</h1>
    <p class="sub">Войди или зарегистрируйся</p>

    <label>Логин <input type="text" id="login" autocomplete="username"></label>
    <label>Пароль <input type="password" id="password" autocomplete="current-password"></label>

    <div class="actions">
        <button type="button" id="btnRegister">Регистрация</button>
        <button type="button" id="btnLogin">Войти</button>
        <button type="button" id="btnGoGame" class="btn" style="display:none">К игре</button>
        <button type="button" id="btnLogout" class="secondary" style="display:none">Выйти</button>
    </div>

    <p class="msg" id="msg"></p>
</div>
<script src="/js/auth.js"></script>
<script>
const msgEl = document.getElementById('msg');

function showMsg(text, isError) {
    msgEl.textContent = text || '';
    msgEl.className = 'msg' + (isError ? ' err' : '');
}

document.getElementById('btnRegister').onclick = async () => {
    const login = document.getElementById('login').value.trim();
    const password = document.getElementById('password').value;
    if (!login || !password) { showMsg('Введи логин и пароль', true); return; }

    const { response, body } = await apiFetch('/auth/register', {
        method: 'POST',
        body: JSON.stringify({ login, password })
    });

    if (response.ok) {
        showMsg('Регистрация OK — теперь нажми «Войти»', false);
    } else {
        showMsg(body?.error || 'Ошибка регистрации', true);
    }
};

document.getElementById('btnLogin').onclick = async () => {
    const login = document.getElementById('login').value.trim();
    const password = document.getElementById('password').value;
    if (!login || !password) { showMsg('Введи логин и пароль', true); return; }

    saveCredentials(login, password);
    const { response, body } = await apiFetch('/auth/login', { method: 'POST' });

    if (response.ok) {
        sessionStorage.setItem('ttt_userId', body); // UUID от /auth/login — нужен для PvP
        window.location.href = '/game.html';
    } else {
        clearCredentials();
        showMsg(body?.error || 'Неверный логин или пароль', true);
    }
};

document.getElementById('btnLogout').onclick = () => logout();

if (isLoggedIn()) {
    const creds = getCredentials();
    document.getElementById('btnGoGame').style.display = '';
    document.getElementById('btnLogout').style.display = '';
    document.getElementById('btnGoGame').onclick = () => { window.location.href = '/game.html'; };
    showMsg('Ты уже вошёл как ' + creds.login, false);
}
</script>
</body>
</html>
```

### Пояснение

- Регистрация **без** Basic — endpoint открыт в Security
- Login: сначала `saveCredentials`, потом запрос — `apiFetch` подставит Basic
- Если уже залогинен — сразу на игру

## Шаг 6.6 — `game-pve.js` (игра против компьютера)

**Путь:** `src/main/resources/static/js/game-pve.js`

### Теория

Цепочка PvE в T04:

```
1. POST /game  body: { "vsComputer": true }  + Basic Auth
   ← сервер: { id, state: PLAYER_TURN, board, currentTurnPlayerId, ... }

2. Клик по клетке → обновляешь board локально (ставишь свою фишку)
   POST /game/{id}  body: { id, board: { board: [[...]] } }  + Basic Auth
   ← сервер: доска после хода компьютера + state

3. state === WIN | DRAW → показать сообщение, блокировать клики
```

**Кто ты на доске:** в API числа `0` пусто, `1` = X, `2` = O.  
В PvE создатель обычно X (`player1`). Смотри `player1Symbol` в ответе, если сомневаешься.

**Чей ход:** `currentTurnPlayerId` должен совпадать с твоим UUID из login (тело ответа `/auth/login`).

### Создай файл

```javascript
requireAuth();

const boardEl = document.getElementById('board');
const msgEl = document.getElementById('msg');
const stateEl = document.getElementById('stateLabel');
const creds = getCredentials();
document.getElementById('userLabel').textContent = 'Игрок: ' + (creds?.login || '');

let gameId = null;
let board = [[0,0,0],[0,0,0],[0,0,0]];
let gameState = null;
let myUserId = null; // заполни после login если сохраняешь UUID отдельно

document.getElementById('btnLogout').onclick = () => logout();

function showMsg(text, isError) {
    msgEl.textContent = text || '';
    msgEl.className = 'msg' + (isError ? ' err' : '');
}

function cellChar(v) {
    if (v === 0) return '';
    if (v === 1) return 'X';
    if (v === 2) return 'O';
    return '?';
}

function canPlay() {
    return gameState === 'PLAYER_TURN';
}

function renderBoard() {
    boardEl.innerHTML = '';
    for (let r = 0; r < 3; r++) {
        for (let c = 0; c < 3; c++) {
            const div = document.createElement('div');
            div.className = 'cell ' + (board[r][c] === 1 ? 'x' : board[r][c] === 2 ? 'o' : '');
            if (!canPlay() || board[r][c] !== 0) div.classList.add('disabled');
            div.textContent = cellChar(board[r][c]);
            if (canPlay() && board[r][c] === 0) {
                div.onclick = () => onCellClick(r, c);
            }
            boardEl.appendChild(div);
        }
    }
    stateEl.textContent = gameState ? 'Состояние: ' + gameState : '';
}

async function onCellClick(row, col) {
    if (!canPlay() || board[row][col] !== 0) return;
    board[row][col] = 1; // ты играешь X в простом PvE; уточни по ответу сервера при необходимости
    renderBoard();
    showMsg('Ход отправляется...', false);

    const { response, body } = await apiFetch('/game/' + gameId, {
        method: 'POST',
        body: JSON.stringify({
            id: gameId,
            board: { board: board }
        })
    });

    if (!response.ok) {
        showMsg(body?.error || 'Ошибка хода', true);
        board[row][col] = 0;
        renderBoard();
        return;
    }

    applyGameDto(body);

    if (body.state === 'WIN' || body.state === 'DRAW') {
        return;
    }
    showMsg('Твой ход!');
}

function applyGameDto(dto) {
    gameId = dto.id;
    board = dto.board.board;
    gameState = dto.state;
    renderBoard();

    if (gameState === 'WIN') {
        const myId = getMyUserId();
        if (dto.winnerId === myId) {
            showMsg('Игра окончена: победа!', false);
        } else if (dto.vsComputer) {
            showMsg('Игра окончена: победил компьютер', false);
        } else {
            showMsg('Игра окончена: поражение', false);
        }
    }
    if (gameState === 'DRAW') showMsg('Ничья!', false);
}

async function startNewPveGame() {
    showMsg('Создаём игру...', false);
    const { response, body } = await apiFetch('/game', {
        method: 'POST',
        body: JSON.stringify({ vsComputer: true })
    });

    if (!response.ok) {
        showMsg(body?.error || 'Не удалось создать игру', true);
        return;
    }

    applyGameDto(body);
    showMsg('Твой ход!');
}

document.getElementById('btnNewPve').onclick = startNewPveGame;

renderBoard();
```

### Пояснение важных моментов

1. **`board[row][col] = 1`** — упрощение: ты создатель и X. Если сервер вернёт ошибку «Not your turn» — смотри `currentTurnPlayerId` и символ в DTO.
2. После каждого ответа **перезаписывай** `board` с сервера — не доверяй только локальной копии (там ход ПК).
3. `gameState !== 'PLAYER_TURN'` — клики блокируются (WIN/DRAW/WAITING).

### Улучшение (сделай после того как базовый PvE заработает)

Сохраняй UUID после login:

```javascript

```

И в `game-pve.js` сравнивай `dto.currentTurnPlayerId` с `myUserId` перед кликом.

## Шаг 6.7 — PvP в браузере (опционально)

> **Когда делать:** после рабочего PvE (шаг 6.6).  
> **Не вставляй куски кода в середину файлов** — ниже три **полных** файла: замени/создай каждый целиком.

### Какие файлы трогать

```
src/main/resources/static/
├── game.html          ← ЗАМЕНИ целиком (шаг 6.7.1)
├── index.html         ← одна строка при login (шаг 6.7.0)
└── js/
    ├── auth.js        ← уже есть, не трогай
    ├── game-pve.js    ← ЗАМЕНИ целиком (шаг 6.7.2) — доска + PvE + ходы в PvP
    └── game-pvp.js    ← СОЗДАЙ целиком (шаг 6.7.3) — только кнопки PvP и лобби
```

**Порядок подключения в `game.html` важен:**

```html
<script src="/js/auth.js"></script>
<script src="/js/game-pve.js"></script>   <!-- сначала: доска, applyGameDto, showMsg -->
<script src="/js/game-pvp.js"></script>   <!-- потом: кнопки PvP, использует функции из pve -->
```

`game-pvp.js` **не** дублирует доску — он только вешает обработчики на кнопки «Создать PvP» и «Обновить список».

**Добавь одну строку** между `if (response.ok) {` и `window.location.href`:

```javascript
document.getElementById('btnLogin').onclick = async () => {
    const login = document.getElementById('login').value.trim();
    const password = document.getElementById('password').value;
    if (!login || !password) { showMsg('Введи логин и пароль', true); return; }

    saveCredentials(login, password);
    const { response, body } = await apiFetch('/auth/login', { method: 'POST' });

    if (response.ok) {
        sessionStorage.setItem('ttt_userId', body); // ← ДОБАВЬ ЭТУ СТРОКУ (UUID от /auth/login)
        window.location.href = '/game.html';
    } else {
        clearCredentials();
        showMsg(body?.error || 'Неверный логин или пароль', true);
    }
};
```

> **Зачем:** `body` — это твой UUID, который вернул `POST /auth/login`. В PvP `game-pve.js` сравнивает его с `currentTurnPlayerId`, чтобы понять, твой ли сейчас ход.
>
> Если на шаге 6.3 ты уже копировал `index.html` из обновлённой инструкции — эта строка **уже есть**, ничего делать не нужно.

### Шаг 6.7.2 — `game-pve.js` (замени файл целиком)

**Путь:** `src/main/resources/static/js/game-pve.js`

Доска, PvE и **ходы в PvP** (символ X/O и проверка очереди). `game-pvp.js` вызывает `applyGameDto` и `showMsg` отсюда.

```javascript
requireAuth();

const boardEl = document.getElementById('board');
const msgEl = document.getElementById('msg');
const stateEl = document.getElementById('stateLabel');
const gameIdEl = document.getElementById('gameIdLabel');
const creds = getCredentials();
document.getElementById('userLabel').textContent = 'Игрок: ' + (creds?.login || '');

let gameId = null;
let board = [[0,0,0],[0,0,0],[0,0,0]];
let gameState = null;
let lastDto = null;

document.getElementById('btnLogout').onclick = () => logout();

function getMyUserId() {
    return sessionStorage.getItem('ttt_userId');
}

function showMsg(text, isError) {
    msgEl.textContent = text || '';
    msgEl.className = 'msg' + (isError ? ' err' : '');
}

function updateGameIdLabel(dto) {
    if (!gameIdEl) return;
    if (!dto || !dto.id || dto.vsComputer) {
        gameIdEl.textContent = '';
        return;
    }
    gameIdEl.textContent = 'ID игры: ' + dto.id;
}

function cellChar(v) {
    if (v === 0) return '';
    if (v === 1) return 'X';
    if (v === 2) return 'O';
    return '?';
}

function myBoardValue() {
    const myId = getMyUserId();
    if (!lastDto || lastDto.vsComputer) return 1;
    if (lastDto.player1Id === myId) return 1;
    if (lastDto.player2Id === myId) return 2;
    return 0;
}

function canPlay() {
    if (gameState === 'WAITING_FOR_PLAYERS') return false;
    if (gameState !== 'PLAYER_TURN') return false;
    if (lastDto && !lastDto.vsComputer) {
        const myId = getMyUserId();
        return myId && lastDto.currentTurnPlayerId === myId;
    }
    return true;
}

function renderBoard() {
    boardEl.innerHTML = '';
    for (let r = 0; r < 3; r++) {
        for (let c = 0; c < 3; c++) {
            const div = document.createElement('div');
            div.className = 'cell ' + (board[r][c] === 1 ? 'x' : board[r][c] === 2 ? 'o' : '');
            if (!canPlay() || board[r][c] !== 0) div.classList.add('disabled');
            div.textContent = cellChar(board[r][c]);
            if (canPlay() && board[r][c] === 0) {
                div.onclick = () => onCellClick(r, c);
            }
            boardEl.appendChild(div);
        }
    }
    stateEl.textContent = stateLabelText();
}

function stateLabelText() {
    if (!gameState) return '';
    if (gameState === 'WIN') return 'Состояние: игра окончена';
    if (gameState === 'DRAW') return 'Состояние: ничья';
    if (gameState === 'PLAYER_TURN') return 'Состояние: ход';
    if (gameState === 'WAITING_FOR_PLAYERS') return 'Состояние: ожидание игрока';
    return 'Состояние: ' + gameState;
}

async function onCellClick(row, col) {
    if (!canPlay() || board[row][col] !== 0) return;

    const symbol = myBoardValue();
    if (symbol === 0) {
        showMsg('Ты не участник этой игры', true);
        return;
    }

    board[row][col] = symbol;
    renderBoard();
    showMsg('Ход отправляется...', false);

    const { response, body } = await apiFetch('/game/' + gameId, {
        method: 'POST',
        body: JSON.stringify({
            id: gameId,
            board: { board: board }
        })
    });

    if (!response.ok) {
        showMsg(body?.error || 'Ошибка хода', true);
        board[row][col] = 0;
        renderBoard();
        return;
    }

    applyGameDto(body);

    if (body.state === 'WIN' || body.state === 'DRAW') {
        return; // сообщение уже выставил applyGameDto — не затираем
    }
    if (body.state === 'PLAYER_TURN') {
        const myId = getMyUserId();
        if (!body.vsComputer && body.currentTurnPlayerId !== myId) {
            showMsg('Жди хода соперника', false);
        } else {
            showMsg('Твой ход!', false);
        }
    } else {
        showMsg('');
    }
}

function applyGameDto(dto) {
    lastDto = dto;
    gameId = dto.id;
    board = dto.board.board;
    gameState = dto.state;
    renderBoard();
    updateGameIdLabel(dto);

    if (gameState === 'WIN') {
        const myId = getMyUserId();
        if (dto.winnerId === myId) {
            showMsg('Игра окончена: победа!', false);
        } else if (dto.vsComputer) {
            showMsg('Игра окончена: победил компьютер', false);
        } else {
            showMsg('Игра окончена: поражение', false);
        }
    }
    if (gameState === 'DRAW') showMsg('Ничья!', false);
    if (gameState === 'WAITING_FOR_PLAYERS') {
        showMsg('UUID игры: ' + dto.id + ' — ждём второго игрока', false);
    }

    if (typeof syncPvpPolling === 'function') syncPvpPolling(dto);
}

async function startNewPveGame() {
    showMsg('Создаём игру...', false);
    const { response, body } = await apiFetch('/game', {
        method: 'POST',
        body: JSON.stringify({ vsComputer: true })
    });

    if (!response.ok) {
        showMsg(body?.error || 'Не удалось создать игру', true);
        return;
    }

    applyGameDto(body);
    showMsg('Твой ход!');
}

document.getElementById('btnNewPve').onclick = startNewPveGame;

renderBoard();
```

### Шаг 6.7.3 — `game-pvp.js` (создай файл целиком)

**Путь:** `src/main/resources/static/js/game-pvp.js`

Только PvP: создание игры, список, join. **Не** рисует доску — использует `showMsg` и `applyGameDto` из `game-pve.js`.

> **Важно:** в PvP браузеры **не связаны** напрямую. Когда соперник ходит или присоединяется — твой экран сам не обновится. Скрипт **опрашивает** `GET /game/{id}` каждые 2 сек:
> - пока ждёшь join (`WAITING_FOR_PLAYERS`);
> - пока ждёшь ход соперника (`PLAYER_TURN`, но `currentTurnPlayerId` — не ты).

```javascript
let waitPollTimer = null;

function stopWaitPoll() {
    if (waitPollTimer) {
        clearInterval(waitPollTimer);
        waitPollTimer = null;
    }
}

function showTurnMessage(dto) {
    const myId = sessionStorage.getItem('ttt_userId');
    if (dto.state === 'WIN' || dto.state === 'DRAW') return;
    if (dto.currentTurnPlayerId === myId) {
        showMsg('Твой ход!', false);
    } else if (dto.state === 'PLAYER_TURN') {
        showMsg('Жди хода соперника', false);
    }
}

async function refreshCurrentGame(id) {
    const { response, body } = await apiFetch('/game/' + id);
    if (!response.ok) return null;
    applyGameDto(body);
    return body;
}

function needsPvpPoll(dto) {
    if (!dto || dto.vsComputer) return false;
    if (dto.state === 'WAITING_FOR_PLAYERS') return true;
    if (dto.state === 'PLAYER_TURN') {
        const myId = sessionStorage.getItem('ttt_userId');
        return myId && dto.currentTurnPlayerId !== myId;
    }
    return false;
}

function syncPvpPolling(dto) {
    if (!needsPvpPoll(dto)) {
        stopWaitPoll();
        return;
    }
    if (waitPollTimer) return;

    const id = dto.id;
    waitPollTimer = setInterval(async () => {
        const updated = await refreshCurrentGame(id);
        if (!updated) return;

        if (!needsPvpPoll(updated)) {
            stopWaitPoll();
            showTurnMessage(updated);
        }
    }, 2000);
}

async function startNewPvpGame() {
    showMsg('Создаём PvP-игру...', false);
    stopWaitPoll();

    const { response, body } = await apiFetch('/game', {
        method: 'POST',
        body: JSON.stringify({ vsComputer: false })
    });

    if (!response.ok) {
        showMsg(body?.error || 'Не удалось создать PvP', true);
        return;
    }

    applyGameDto(body);
    showMsg('UUID игры: ' + body.id + ' — ждём второго игрока. Скажи сопернику этот ID.', false);
}

async function joinGame(id) {
    showMsg('Присоединяемся...', false);
    stopWaitPoll();

    const { response, body } = await apiFetch('/game/' + id + '/join', {
        method: 'POST'
    });

    if (!response.ok) {
        showMsg(body?.error || 'Не удалось присоединиться', true);
        return;
    }

    applyGameDto(body);
    showTurnMessage(body);
}

async function refreshLobby() {
    const listEl = document.getElementById('lobbyList');
    listEl.innerHTML = '';

    const { response, body } = await apiFetch('/game/available');

    if (!response.ok) {
        showMsg(body?.error || 'Не удалось загрузить список', true);
        listEl.innerHTML = '<li>Ошибка загрузки</li>';
        return;
    }

    if (!body || body.length === 0) {
        listEl.innerHTML = '<li>Нет игр в ожидании</li>';
        return;
    }

    body.forEach(game => {
        const li = document.createElement('li');
        li.textContent = game.id + ' ';
        const btn = document.createElement('button');
        btn.type = 'button';
        btn.className = 'secondary';
        btn.textContent = 'Присоединиться';
        btn.onclick = () => joinGame(game.id);
        li.appendChild(btn);
        listEl.appendChild(li);
    });
}

document.getElementById('btnNewPvp').onclick = startNewPvpGame;
document.getElementById('btnRefreshLobby').onclick = refreshLobby;
```

### Частые ошибки PvP в браузере

| Симптом | Причина |
|---------|---------|
| `btnNewPvp is null` | Не обновил `game.html` — нет кнопок PvP |
| `showMsg is not defined` | `game-pvp.js` подключён **до** `game-pve.js` |
| `Not your turn` | Кликаешь не в свою очередь |
| Пустой список | Alice ещё не создала PvP-игру |
| `Cannot join your own game` | Тот же логин пытается join к своей игре |
| Игра «началась», но никто не ходит | У Alice экран застрял на `WAITING_FOR_PLAYERS` после join Bob | Добавь `pollUntilOpponentJoins` в `game-pvp.js` (шаг 6.7.3) |

| В PvP всегда X | Не заменил `game-pve.js` на версию из шага 6.7.2 | |

## Шаг 6.8 — Что ты должен видеть в браузере (чеклист)

| Действие | Ожидание |
|----------|----------|

## Частые ошибки (браузер)

| Симптом | Причина | Решение |
|---------|---------|---------|
| 401 на `/index.html` или `/test.txt` | `permitAll` в Security **недостаточно** — добавь `isPublicPath` в `AuthFilter` |
| 401 на `/game` из JS | Нет Basic в fetch | `authHeader()` в `apiFetch` |
| CORS ошибка | Редко при localhost | Убедись что открываешь `localhost:8080`, не `file://` |
| `Not your turn` | Ходишь не в свою очередь / неверный символ | Смотри DTO: `currentTurnPlayerId`, `state` |
| Доска не обновляется | Не применил ответ сервера | `applyGameDto(body)` после каждого POST |
| Пустой экран game.html | Нет `game-pve.js` или ошибка в консоли | F12 → Console |

## Не делай так (антипаттерны)

1. **Не** копируй целиком старый `HomeController` из 1.0 — там нет auth и старый API без `POST /game`.
2. **Не** храни пароль в `localStorage` навсегда — только `sessionStorage` для учебы.
3. **Не** открывай API (`/game/**`) в `permitAll` — только статика и `/auth/*`.
4. **Не** генерируй `gameId` на клиенте для **создания** игры — только сервер в `createGame`.
