## Рабочая директория

**Все команды `./gradlew`** — только из:

```bash
cd src/TicTacToe_1.2_sql_auth
./gradlew bootRun
```

Полный путь:

```
.../AP1_Jv_T04B.ID_1421426-1/src/TicTacToe_1.2_sql_auth/
```

Там должны лежать: `gradlew`, `build.gradle.kts`, `src/main/java/tictactoe/`.

---

## JDK — обязательно перед bootRun

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
java -version   # должно быть 21.x, НЕ 26
```

Java 26 → ошибка `* What went wrong: 26.0.1`. Подробнее в `T04_00_СБОРКА_ПРОЕКТА.md`.
